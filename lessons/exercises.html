🎯 Mission 2: Hands-On Practice Exercises

Elevate your understanding beyond the class scripts. Modify, break, and rebuild these systems to master ReAct Agents!

  1. Lesson 06 1. Build an EMI loan calculator tool

    Modify `06_custom_tool_design.py` to add a loan EMI (Equated Monthly Installment) calculator tool. The tool should take parameters like `principal_loan_amount`, `annual_interest_rate`, and `tenure_months`, perform float calculations, and output a structured pricing description. Rerun the agent to calculate pricing totals for complex loan queries.

    Vibe Prompt: Modify 06_custom_tool_design.py to add an EMI loan calculator tool. Use type hints, add clear docstrings, and test it in the create_agent loop.

  2. Lesson 07 2. Invoke live Google Serper searches

    Ensure `SERPER_API_KEY` is configured in your `.env`. Open `07_api_driven_tools.py` and run a live tourist spot or current event query (e.g. "Find what cultural festivals are happening in Tokyo in 2026."). Check how the agent dynamically invokes `google_search` to fetch real-time facts instead of relying on weather indicators.

    Vibe Prompt: Rerun 07_api_driven_tools.py with a general knowledge query using your active SERPER_API_KEY to see live search outputs.

  3. Lesson 08 3. Probe the SELECT-only read security guard

    Try querying `08_database_sql_tool.py` with destructive write queries like "DROP TABLE products" or "UPDATE products SET price = 0". Observe how our custom read-hardened validation guard in `query_products_database` blocks execution on the spot to secure the relational database.

    Vibe Prompt: Test query_products_database tool in 08_database_sql_tool.py with a write/update statement to inspect the security guard message.

  4. Lesson 11 4. Enhance the visual Gradio blocks capstone

    Add a new button called "Clear Chat History" or a new slider called "Max Tokens" in the Gradio dashboard interface. Edit `11_gradio_agent_ui.py` to integrate it into the blocks container and test your custom styling variations.

    Vibe Prompt: Add a clear history button in 11_gradio_agent_ui.py and update the Gradio Blocks container layout to render it gracefully.

🚀 How to execute programs

To run any lesson file or verified practice script inside the pre-configured virtual environment, use the command:

.venv\Scripts\python.exe [filename].py

For example, to run the capstone dashboard: .venv\Scripts\python.exe 11_gradio_agent_ui.py
